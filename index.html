Google Sheets 연동

스프레드시트 데이터를 실시간 불러옵니다

1단계: 템플릿 파일 다운로드

아래 버튼을 눌러 CSV 템플릿을 다운로드한 후, Google Sheets/Excel에서 열어 데이터를 입력하세요.

2단계: Google Sheets 게시

Google Sheets에서 파일 → 공유 → 웹에 게시 → CSV 형식으로 게시한 URL이 필요합니다.

자세한 방법은 GOOGLE_SHEETS_GUIDE.md 참고

빠른 가이드

  1. Google Sheets 새 문서 만들기
  2. spreadsheet/creatives_template.csv 가져오기
  3. 파일 → 공유 → 웹에 게시 → CSV 선택 → 게시
  4. 생성된 URL을 위에 붙여넣기 → 연결하기

Google Drive 자동 연동 ✨

이미지/영상 URL을 만들 필요 없이 Google Drive 공유 링크를 그대로 붙여넣으면 됩니다!

  1. Google Drive에 이미지/영상 업로드
  2. 파일 우클릭 → 공유 → "링크가 있는 모든 사용자"
  3. 링크 복사 → 스프레드시트 thumbnail_url / video_url 칸에 그대로 붙여넣기
  4. 대시보드가 자동으로 변환하여 표시! 🎉
예: https://drive.google.com/file/d/1abc...XYZ/view?usp=sharing
→ 자동 변환 후 대시보드에 미리보기 표시 ✓
